# docs/figures

ภาพประกอบเอกสาร ไม่ได้ถูกอ้างถึงจากโค้ดใด ๆ

`flows/` คือแผนผังการทำงาน 6 ภาพ ตั้งชื่อเป็น "ภาพที่ 3.1" ถึง "3.6" ตามลำดับภาพในรายงาน

| ภาพ | เนื้อหา |
|---|---|
| 3.1 | สมัครสมาชิกและเข้าสู่ระบบ |
| 3.2 | การเช็คอินรับแต้มที่ร้านค้า |
| 3.3 | การแลกรางวัล (ร้านสแกนหักแต้ม) |
| 3.4 | การจัดอันดับร้านดัง |
| 3.5 | การเช็คชื่อกิจกรรมโรงเรียน |
| 3.6 | การสมัครเป็นร้านค้า |

เดิมอยู่ในโฟลเดอร์ชื่อ `Claude outputs/` ที่ root ของ repo ย้ายมาที่นี่เพื่อให้
root สะอาดและชื่อโฟลเดอร์บอกได้ว่าไฟล์ข้างในคืออะไร ไฟล์ไม่ได้ถูกแก้หรือบีบอัด

รวมประมาณ 2.2 MB ถ้าจะเพิ่มภาพใหม่ ควรบีบอัดก่อน commit
